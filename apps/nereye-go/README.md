# Expo Go

1. Visual Studio veya CLI ile API: `http://0.0.0.0:5079`
2. Telefonda **Expo Go**
3. `apps/nereye-go` içinde `npx expo start`
4. QR okut. Aynı Wi-Fi şart (veya `npx expo start --tunnel`)
5. Giriş ekranındaki API: `http://192.168.1.248:5079` (PC’nin LAN IP’si değişirse düzelt)

Kayıt için herhangi bir e-posta + şifre (min 8, büyük/küçük/rakam/sembol).
